プライバシー ポリシー

Relay Edit　制定日 2026年11月10日

1. このポリシーについて

hacoeivom（以下「運営者」）は、業務用の編集管理システム「Relay Edit」（以下「本システム」）で取り扱う利用者の情報について、次のとおり定めます。

2. 受け取る情報

  • Google アカウントでログインしたときに Google から受け取る、名前とメールアドレス
  • ログインした日時と、使った端末の種類（ブラウザが送る端末の情報）
  • 本システムの通知を受け取る設定をした端末の、通知の送り先の情報
  • 利用者が本システムに入力した内容（修正の依頼、承認の操作など）

Google アカウントのパスワード、連絡先、カレンダー、ドライブなど、上に書いた以外の情報は受け取りません。

3. 使い道

  • ログインした人を見分け、役割（admin・ディレクター・編集者）に応じて使える機能を決めるため
  • だれがいつログインしたかを記録し、不正な利用を防ぐため
  • 工程の進み具合や承認の依頼を、本人の端末に通知するため

これ以外の目的には使いません。Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

4. 第三者への提供

法令に基づく場合を除き、受け取った情報を第三者に提供・販売しません。

5. 保管と管理

情報は、運営者が管理するコンピュータに保存し、運営者と、本システムで権限を与えられた管理者だけが扱います。ログインの記録を見られるのは admin の権限を持つ人だけです。

6. 削除・お問い合わせ

自分の情報の確認・削除を希望するときや、このポリシーについてのお問い合わせは、info@hacoeivom.com までご連絡ください。

7. 改定

このポリシーを改定するときは、このページでお知らせします。
